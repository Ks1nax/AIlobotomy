**AIlobotomy** — операционная для языковых моделей, которые работают у вас на компьютере. Загрузите любую модель с Hugging Face, вырежьте ей слои, перемешайте их, насыпьте шума в веса, заставьте путать *кошку* с *собакой*, вживите пиратское настроение — и задавайте вопросы, сравнивая ответы со здоровой копией.

Это игрушка, учебное пособие и маленькая лаборатория интерпретируемости в одном окне. Любое изменение отменяется одной кнопкой.

## ✨ Что можно делать

| | Инструмент | Что происходит с пациентом |
|---|---|---|
| 🔪 | **Удалить слои** | Вырезать любые слои. Середина стека удивительно живучая, первые и последние слои — нет. |
| 🧬 | **Дублировать** | Прогнать сигнал через слой 2–10 раз подряд. Модель начинает зацикливаться или «передумывать». |
| 🔀 | **Перемешать / Развернуть** | Изменить порядок, в котором слои обрабатывают сигнал. |
| 🌫 | **Шум** | Гауссов шум в веса: только внимание, только MLP, нормализация или эмбеддинги слов. |
| 📏 | **Масштаб** | Умножить веса на любое число, в том числе отрицательное. |
| 🔊 | **Громкость слоя** | Вклад слоя в общий поток: `0` — пропустить, `2` — усилить, `-1` — инвертировать. |
| 👁 | **Головы внимания** | Отключить отдельные головы. |
| 🧠 | **Без внимания / Без MLP** | Обнулить блоки целиком. Без MLP модель говорит гладко, но забывает факты. |
| ✂️ | **Обрезка** | Обнулить N % самых слабых весов. |
| 🧱 | **Огрубление** | Сжать веса до 1–8 бит. |
| 🐱 | **Путаница слов** | Поменять два слова в словаре: модель думает «кошка», а говорит «собака». |
| 🕳 | **Забыть слово** | Стереть слово из восприятия модели. |
| 💉 | **Вживить эмоцию** | Векторы управления: радость, злость, пират, сонливость, голод, паранойя или свой вариант. |

**Чтобы осмотреть пациента:**

- **Разговор** — пациент и здоровый донор отвечают на один вопрос бок о бок, текст появляется по мере генерации.
- **Логит-линза** — какое слово модель «держит в голове» после каждого слоя.
- **IQ-тест** — 10 простых вопросов и замер перплексии. Видно, как падает интеллект с каждым разрезом.

**Медкарта** записывает каждую операцию. Любую можно выключить, переставить или удалить — пациент пересоберётся из донора без неё. Медкарту можно выгрузить как **рецепт** и поделиться им, а покалеченную модель сохранить на диск как обычную модель Hugging Face.

## 🚀 Быстрый старт

### Windows

1. Установите [Python 3.10+](https://www.python.org/downloads/) и отметьте галочку **«Add python.exe to PATH»**.
2. [Скачайте репозиторий](../../archive/refs/heads/main.zip) и распакуйте куда угодно, например в `D:\programs\AIlobotomy`.
3. Запустите **`start.bat`**.

Первый запуск создаёт виртуальное окружение и ставит PyTorch: версию с CUDA, если найдена видеокарта NVIDIA, иначе версию для процессора. Потом открывается браузер на **http://127.0.0.1:7861**.

### Linux / macOS

```bash
git clone https://github.com/Ks1nax/AIlobotomy.git
cd AIlobotomy
./start.sh
```

На Apple Silicon работает через MPS.

### С какой модели начать

| Модель | Размер | Заметки |
|---|---|---|
| `Qwen/Qwen2.5-0.5B-Instruct` | 0.5B | **Лучший первый пациент.** Быстрая даже на процессоре, 24 слоя, понимает русский |
| `HuggingFaceTB/SmolLM2-360M-Instruct` | 360M | Крошечная и быстрая, только английский |
| `Qwen/Qwen3-0.6B` | 0.6B | Новее и умнее, 28 слоёв |
| `Qwen/Qwen2.5-1.5B-Instruct` | 1.5B | Заметно умнее, лучше с видеокартой |

Подойдёт почти любая причинная языковая модель с Hugging Face в стиле Llama, Qwen, Mistral, Phi, GPT-2 или GPT-NeoX. Просто вставьте её id в окно выбора модели.

## 🧪 Опыты

Готовые рецепты для `Qwen2.5-0.5B-Instruct` лежат в [`recipes/`](recipes). Загрузите через **«Импорт рецепта»**.

- **Пьяный философ** — громкость `2.5` на трёх средних слоях. Сначала уверенно, потом всё страннее.
- **Амнезия** — обнулите MLP в слоях 4–12 и спросите столицу Франции. Речь гладкая, факты развалились.
- **Кошкопёс** — путаница *кошка* ↔ *собака* везде, потом спросите про собак.
- **Депрессивный пират** — «Пират» в один средний слой и «Радость» с отрицательной силой в соседний.
- **Найди критический слой** — удаляйте слои по одному и после каждого запускайте IQ-тест. Какой убивает пациента?

Нашли что-то смешное? Поделитесь рецептом в [Discussions](../../discussions) или пришлите PR в `recipes/`.

## 🛠 Как это устроено

В памяти живут две копии модели: **донор**, которого никто не трогает, и **пациент**. Структурные операции пересобирают стек слоёв и переиндексируют KV-кэш. Операции с весами меняют тензоры на месте. Громкость слоя и эмоции — это хуки на слоях, которые переписывают остаточный поток.

Медкарта — источник истины: когда вы выключаете или переставляете операцию, пациент заново клонируется из донора и вся медкарта применяется снова. Поэтому всё обратимо, а рецепты воспроизводимы (шум и перемешивание запоминают свой seed).
